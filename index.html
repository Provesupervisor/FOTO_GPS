Ubicación bloqueada

  1. En la página: toca el ícono ⚙︎ / 🔒 a la izquierda de la dirección web → Permisos → Ubicación → Permitir.
  2. En el teléfono: Ajustes → Aplicaciones → Chrome (o Navegador Huawei) → Permisos → Ubicación → Permitir mientras se usa, con “Usar ubicación precisa” activado.
  3. GPS encendido: baja la barra de notificaciones y activa Ubicación.
  4. Vuelve aquí y toca Reintentar.
